# ИИ агент поддержки

Чат для подбора продуктов из выданного каталога Softline. Поддерживает поиск конкретной лицензии и подбор от задачи клиента.

## Локальный запуск

Нужен Node.js 24.15.0. Скачайте `Mindbox.yml.gz.xml` из [папки материалов](https://drive.google.com/drive/folders/1kxvQQf_vvg7ZsmX9dB6Qot8AM7lHgu2U) и передайте путь при импорте.

```sh
npm ci
npm run catalog:import -- /path/to/catalog.xml
npm run catalog:check
npm run decision:check
npm run chat:check
npm run product:check
npm run dev
```

Для чата задайте `POLZA_API_KEY` в локальном `.env.local` по образцу `.env.example`. Откройте [localhost:3000](http://localhost:3000). База создаётся в `data/t06/catalog.sqlite`. Приложение и проверочный скрипт используют этот же файл.

`npm run chat:check` проверяет маршрут чата на загруженном каталоге с тестовыми ответами моделей, без расхода баланса.

## Проверка полного сценария

- Выберите подтверждённую позицию с ценой в последнем ответе или попросите проверить позицию для проекта КП. Раздел «Демо-КП и счёт» сформирует два отдельных печатных HTML-файла. Сервер сверяет цену, количество и тариф по каталогу. Файлы предназначены для демонстрации, реквизиты продавца и условия оплаты уточняет менеджер магазина.
- Кнопка «Передать менеджеру» сохраняет последние реплики после подтверждения. В `/manager` сотрудник видит диалог, отвечает клиенту и может закрыть обращение. Ответ появляется в том же клиентском чате. Для входа задайте `MANAGER_ACCESS_TOKEN` в окружении или `.env.local`.
- `/manager/knowledge` показывает историю действий и факты из проверенных позиций. Менеджер может добавить статью с источником и ключевыми фразами. Релевантные статьи помощник использует в следующих ответах. В журнал не попадают текст переписки и реквизиты покупателя.
- Очередь, база знаний и журнал хранятся в отдельном файле `data/t06/support.sqlite`. Переменная `SUPPORT_DB` задаёт другой путь. `npm run product:check` проверяет документы, очередь и базу знаний на изолированной БД.

DeepSeek ведёт разговор и вызывает поиск по каталогу через Mastra. Перед подтверждением конкретных лицензий инструмент [`verifyFit`](lib/support.ts) отправляет выбранные позиции и условия клиента в [Gemini Decision 1 через Polza SystemOne](lib/decision.ts). Карточки показывают полученную оценку для каждой проверенной позиции. Цены и признаки доступности относятся к снимку каталога. Исходный каталог и переписки хранятся локально.
