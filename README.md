# ИИ агент поддержки

Прототип для интернет-магазина Softline, задача T06 хакатона ИИкузница. Чат проверяет конкретную лицензию или подбирает её по задаче покупателя, формирует демо-КП и проект счёта, отвечает по справке и передаёт сложные вопросы менеджеру вместе с контекстом. Менеджер отвечает в тот же чат и может опубликовать проверенный ответ в базе знаний.

**Публичный стенд** — [чат покупателя](https://201-24-61-166.sslip.io/) · [кабинет менеджера](https://201-24-61-166.sslip.io/manager). Чат доступен без ключа. Для кабинета нужен отдельный токен стенда.

## Запуск из чистого клона

Нужен Node.js 24.15.0, версия закреплена в `.nvmrc`. Скачайте `Mindbox.yml.gz.xml` и укажите фактический путь к файлу. Это готовый XML объёмом 292 МБ. [Каталог](https://drive.google.com/file/d/1UHi-oE_ZGsiCMAZVbIBdclkl6G6Uq9Ue/view) · [Все материалы задачи](https://drive.google.com/drive/folders/1kxvQQf_vvg7ZsmX9dB6Qot8AM7lHgu2U)

```sh
git clone https://github.com/warbr1ng3r/ai-forge-support.git
cd ai-forge-support
npm ci
npm run catalog:import -- "/path/to/Mindbox.yml.gz.xml"
cp .env.example .env.local
```

Заполните `POLZA_API_KEY` в `.env.local` для чата на живых моделях. Для входа на локальную страницу `/manager` задайте собственный `MANAGER_ACCESS_TOKEN` в том же файле и используйте это значение при входе. Запустите `npm run dev` и откройте [локальное приложение](http://localhost:3000). Для запуска собранной версии используйте `npm run build`, затем `npm start`.

Импорт создаёт `data/t06/catalog.sqlite`. Очередь, ответы менеджеров, база знаний и журнал используют `data/t06/support.sqlite`. При смене путей задайте `CATALOG_DB` и `SUPPORT_DB` в окружении команд импорта, проверок и запуска. Для запуска в Ubuntu/Timeweb предусмотрены [инструкции с systemd и HTTPS](deploy/README.md).

## Автоматические проверки

Выполните после импорта каталога. Команды можно запускать без ключа Polza и токена менеджера.

```sh
npm run catalog:check
npm run decision:check
npm run chat:check
npm run product:check
npm run build
npm run typecheck
```

- `catalog:check` сверяет импорт и поиск по XML-каталогу.
- `decision:check` проверяет логику оценки применимости лицензий с тестовыми ответами Decision 1.
- `chat:check` проверяет маршрут чата и инструменты на исходном каталоге с тестовыми ответами моделей.
- `product:check` проверяет документы по каталогу, очередь, ответы менеджера и базу знаний. Для пользовательских данных создаёт временную БД.

Живые модели можно проверить на публичном стенде или в локальном запуске с ключом Polza.

## Сценарий для жюри

1. Спросите в чате «Нужна бессрочная КриптоПро CSP 5.0 на один Windows Server для компании, прежней лицензии нет. Подойдёт ли позиция 197894? Если нет, укажите подходящий вариант из каталога с ценой». Ожидаемый подбор — первичная серверная лицензия `197958` за 70 000 ₽ по снимку каталога. `197894` предназначен для обновления лицензии рабочего места.
2. В карточке откройте «Демо-КП и счёт». Укажите вымышленного покупателя и количество 1. Скачайте КП и проект счёта, проверьте в обоих файлах артикул и сумму. Файлы печатаются из браузера и предназначены для демонстрации. Для недоступных позиций фактическую поставку подтверждает менеджер.
3. Нажмите «Передать менеджеру», добавьте причину и подтвердите передачу. Войдите в `/manager`, откройте обращение с тем же номером и отправьте ответ. Он появится в исходном чате.
4. В `/manager/knowledge` добавьте проверенный факт из ответа со ссылкой на источник и ключевой фразой «памятка t06 elbrus». Например, для Dr.Web Server Security Suite 11.1 for UNIX на Astra Linux SE 8.1 «Ленинград» (E2K) в документации указан патч `8.120200429SE81`. Нажмите «Новый подбор» и спросите «Памятка T06 Elbrus. Какой патч нужен для Dr.Web 11.1 на Astra Linux SE 8.1 „Ленинград“? Дайте код и источник». Агент должен вернуть код и ссылку. [Системные требования Dr.Web](https://cdn-download.drweb.com/pub/drweb/unix/server/11.1/documentation/html/en/sysrequirements.htm)

Для проверки с открытым запросом начните новый чат и напишите «Нужна защита почтового и файлового серверов. Что уточнить для подбора?». Агент должен выяснить параметры инфраструктуры и лицензии перед рекомендацией.

## Как работает прототип

TypeScript и Next.js обслуживают интерфейс и серверные маршруты. Vercel AI SDK передаёт поток ответа. DeepSeek V4.1 Flash через Polza получает недавние сообщения диалога, а Mastra вызывает инструменты поиска по каталогу и справке. Для проверки конкретных позиций [`verifyFit`](lib/support.ts) передаёт условия и сведения из каталога в [Gemini Decision 1 через Polza SystemOne](lib/decision.ts). Карточки показывают полученную оценку. Цены и доступность относятся к снимку каталога, официальные документы и заказы оформляет магазин.

Последние сообщения чата с ИИ и карточки товаров сохраняются в хранилище текущей вкладки. Снимок каталога хранится на сервере. Переданные менеджеру обращения и его ответы сохраняются в локальной SQLite вместе с базой знаний и журналом событий. Для демонстрации используйте вымышленные данные.
